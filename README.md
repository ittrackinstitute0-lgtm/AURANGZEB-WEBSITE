# AURANGZEB MIRANI – Royal Dostana Department 👑

A hilarious, interactive, modern friendship comedy website dedicated to a legendary group of Pakistani friends.

## 🌟 How to View the Website
You can view this website in two easy ways:

### Option 1: Direct Double Click
Simply double-click [`index.html`](index.html) in this folder. It will instantly open in your default browser (Google Chrome, Edge, Brave, etc.) with all animations, glassmorphism designs, and interactive sounds working offline!

### Option 2: Local HTTP Server (Optional)
If you prefer running a local development server:
```bash
python -m http.server 8000
```
Then open: [http://localhost:8000](http://localhost:8000)

## 🚀 Key Interactive Features

- **Hero Section**: Animated floating emojis, ambient glowing orbs, breaking news live ticker marquee, and "ENTER THE LEGENDARY WORLD" smooth scroll.
- **Pure Web Audio Synthesizer**: Custom synthesized sound effects (Royal Trumpets, Cannon Blast, Comedy Slapstick Boing, Dramatic Soap Opera Sting, Success Chimes) without external audio file dependencies.
- **Friendship Meter (Dosti Ka X-Ray)**: Select any pair of friends to compute their comedy friendship percentage with animated SVG circular gauge. Selecting Aurangzeb Mirani Sahab triggers the **1000% Shahi Wafaadari** easter egg with confetti!
- **Funny Dialogues Generator**: Click "Naya Chawal Suno 🎲", copy quotes, or listen to voice synthesis.
- **Dosti Awards (Oscars 2026)**: Interactive award cards with celebratory taaliyan and confetti.
- **Top Secret Dosti Files**: Classified dossiers and live stats counter (48,291 Bahany, 12,450 Chai cups, 999+ voice notes, 74 cancelled trips).
- **Simulated WhatsApp Chat**: Real-time comedy group banter simulator with "Send Chawal" button.
- **Desi Sound Effects Toggle**: Easily turn audio effects on or off anytime.
